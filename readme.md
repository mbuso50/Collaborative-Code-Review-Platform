# Collaborative Code Review Platform

A TypeScript-based API-driven service that enables developers and teams to post code snippets, request feedback, and collaborate on reviews in real time.

## Features

-  **Authentication & User Management** - JWT-based auth with RBAC
-  **Projects & Repositories** - Organize code submissions by project
-  **Code Submissions** - Upload and manage code snippets/files
-  **Inline Comments** - Comment on specific lines of code
-  **Review Workflow** - Track submission status and review history
-  **Real-time Notifications** - WebSocket-based live updates
-  **Analytics Dashboard** - Project-level statistics and insights

## Tech Stack

- **Backend**: Node.js, Express, TypeScript
- **Database**: PostgreSQL
- **Authentication**: JWT, bcryptjs
- **Real-time**: WebSocket (Socket.io)
- **Validation**: Joi
